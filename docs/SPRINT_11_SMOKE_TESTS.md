# Sprint 11 Smoke Tests

Sprint 11 makes the first screen calm and action-oriented after the Sprint 10 IA shell.

## Milestone checklist

- [x] Hub screen has three primary cards: Profile, Campaign, Questions.
- [x] Continue Last Quest CTA exists and opens the focused solve screen.
- [x] Compact stats strip includes XP, Shards, streak/rating, bosses defeated, and reviews due.
- [x] Companion dialogue bubble is present.
- [x] Full editor and replay theater stay off the Hub.
- [x] Profile surface includes player card, rewards, recent attempts, and review reminders.

## Acceptance checks

- [x] First screen does not show full editor.
- [x] First screen does not show full replay theater.
- [x] User can choose Profile, Campaign, or Questions within 5 seconds.
- [x] Rewards/stats are compact, not dashboard-heavy.
- [x] Pixel RPG tone is visible but not noisy.

## Commands

```bash
npm run smoke:sprint11
```
