# Sprint 15 Smoke Tests

Sprint 15 applies the Undertale-like-but-happier pixel RPG visual system while preserving accessibility and coding readability.

## Milestone checklist

- [x] Reusable visual tokens exist in CSS:
  - void, night, panel, panel-2, border, border-muted, text, text-muted
  - cyan, teal, gold, pink, red, green, purple
- [x] Pixel panel/button/dialogue primitives exist.
- [x] Sprite/bit-character placeholder class exists.
- [x] Visible focus states exist for keyboard users.
- [x] Status states include text labels, not color alone.
- [x] Code editor and long problem text stay readable with normal/monospace fonts.
- [x] Motion respects reduced-motion preference.
- [x] Mobile/narrow viewport stacks solve panes.

## Acceptance checks

- [x] UI reads as retro pixel RPG.
- [x] Mood remains happier/cozy, not grim.
- [x] Code editor remains professional and readable.
- [x] Question body remains readable.
- [x] Motion is controllable.

## Commands

```bash
npm run smoke:sprint15
```
