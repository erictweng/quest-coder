# Sprint 5 Visual Quality Checklist

Each pack must meet the PRD visual bar before it counts toward the personal library.

## Required checks per pack

- [ ] Scene metaphor is original; no real-game characters, logos, maps, or UI.
- [ ] Replay highlights source-code line movement.
- [ ] Replay shows data movement or pointer movement in the scene.
- [ ] Outcome visuals are distinct for pass/fail/crash/budget/loop/off-end states.
- [ ] Large inputs stay readable/responsive under the 3,000-event cap.
- [ ] Reference solution passes through the same runner used by the app.
- [ ] Boss challenge has at least one replay case.

## Sprint 5 checked packs

- [x] Timequake / Search Rotated Array — array doors/skyline.
- [x] Plain Binary Search — array doors/skyline.
- [x] Reverse Linked List — portal/island chain with pointer relinking.
- [x] Merge Two Sorted Lists — twin portal chains with pointer movement.
- [x] Linked List Cycle — fast/slow portal scouts with cycle visibility.
