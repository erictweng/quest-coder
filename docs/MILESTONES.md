# Quest Coder Milestones

## Gates

### Gate 0 — Decisions locked

Ready when:
- Stack selected.
- First question order selected.
- Review interval defaults selected.
- Reward placeholder selected.
- App name decision made or deferred explicitly.

### Gate 1 — Timequake boss runs on server

Ready when:
- Server CPython sandbox runs Search in Rotated Sorted Array.
- Result types are distinct.
- Read budget catches linear scan.
- Timeline replay can be rendered from sandbox output.

### Gate 2 — Personal MVP usable

Ready when:
- Eric can sign in.
- Library works.
- Quests unlock in order.
- Code/attempt/progress persist.
- Boss fight and victory replay work.
- 5 questions are cleared end to end.

### Gate 3 — Reinforcement works

Ready when:
- Stale reviews return beaten questions.
- Surprise battles pick eligible studied topics.
- Topic stats update.
- Stack/tree/graph scene foundations exist.

### Gate 4 — Public launch safe

Ready when:
- Sandbox security review passes.
- Rate limits and abuse protection exist.
- Problem text is original.
- Public signup/onboarding works.

## MVP scope boundary

Personal MVP includes:
- Python only.
- One user first, but with real auth/persistence.
- Timequake + first linked-list packs.
- Server runner, replay, quest packs, boss fights.
- Stale reviews if possible, but public hardening can wait.

Personal MVP excludes:
- Rewards beyond placeholder.
- Social/friend list.
- Multiple languages.
- Public untrusted users.
- Large library coverage.
