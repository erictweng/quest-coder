# Sprint 14 Smoke Tests

Sprint 14 moves advanced systems into contextual moments instead of permanent workspace clutter.

## Milestone checklist

- [x] Replay theater is only inside the Animation tab/drawer.
- [x] Failed runs suggest `View Animation` from the result drawer.
- [x] Quest clears show a compact reward toast.
- [x] Boss clears show a larger but brief boss victory moment.
- [x] Next quest/campaign unlock is called out after reward.
- [x] Attempt history lives in Submissions, not default workspace chrome.
- [x] Review due state remains in Hub/Profile/Campaign context, not solve-screen clutter.
- [x] Reduced-motion safety is explicit: replay only moves when the user presses Play/Step.

## Acceptance checks

- [x] Animation/replay is optional and discoverable.
- [x] Rewards are visible after clears but non-blocking.
- [x] Attempt history remains accessible.
- [x] Review reminders guide without nagging.
